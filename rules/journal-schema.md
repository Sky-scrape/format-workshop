# 期刊规则集 Schema 设计

> 目标期刊 = 一份数据文件。新增期刊只允许改数据，不允许改代码。
> 本设计同时覆盖中文经管期刊与英文经管期刊，两者共用同一套 schema。

---

## 1. 三条硬约束

1. **字段用中立语义命名**：不出现 `clc_code`、`author_bio`、`zh_abstract` 这类绑定某一地区或语言的字段名。
2. **代码中不得出现期刊特判**：不存在 `if journal.id == 'xxx'` 或 `if journal.country == 'CN'`。所有差异必须下沉到数据。
3. **同一 block 类型在中英文语境下名称不同，但在 schema 中是同一个类型**，差异由 `scheme`、`lang`、`placement` 等属性表达。

违反以上任一条，扩展性即失效。

---

## 2. 顶层结构

```json
{
  "schema_version": "0.1",
  "journal":       { "id", "name_zh", "name_en", "language", "verification" },
  "page":          { "size", "margin_mm", "columns" },
  "blocks":        [ ... ],          // 有序的必备块序列
  "typography":    { ... },          // 字体字号行距
  "headings":      { ... },          // 标题层级与编号体系
  "citation":      { ... },          // 引用体系
  "tables":        { ... },          // 表格规格
  "figures":       { ... },
  "limits":        { ... },          // 只用于提醒，不触发修改
  "statements":    { ... }           // 必备声明
}
```

`journal.language` 决定语言能力，**不由稿件语言决定**。英文期刊的中国作者不需要中英对照摘要；中文期刊的英文摘要则是必备项。这一条如果搞反，输出会整篇错。

---

## 3. blocks：中立命名对照

`blocks` 是一个**有序数组**，顺序即输出顺序。每项至少包含 `type` 与 `required`。

| type（中立） | 中文经管期刊叫法 | 英文经管期刊叫法 | 关键属性 |
|---|---|---|---|
| `title` | 标题 | Title | `lang` |
| `authors` | 作者 | Authors | |
| `affiliations` | 作者单位 | Affiliations | |
| `corresponding_author` | 通讯作者 | Corresponding author | `mark` 标记方式 |
| `abstract` | 摘要 | Abstract | `lang`、`max_chars` |
| `keywords` | 关键词 | Keywords | `lang`、`count_min/max` |
| `classification_code` | 中图分类号 / JEL 分类号 | JEL codes | **`scheme`：`CLC` 或 `JEL`** |
| `document_code` | 文献标识码 | —（不使用） | `scheme` |
| `author_note` | 作者简介 | Author notes | `placement`：`footnote` 或 `section` |
| `funding_statement` | 基金项目 | Funding | `placement` |
| `received_date` | 收稿日期 | Received | |
| `body` | 正文 | Body | |
| `appendix` | 附录 | Appendix | |
| `acknowledgement` | 致谢 | Acknowledgements | |
| `references` | 参考文献 | References | `style_id` |
| `data_availability` | 数据可得性声明 | Data availability | |
| `conflict_of_interest` | 利益冲突声明 | Conflict of interest | |
| `highlights` | —（不使用） | Highlights | |
| `graphical_abstract` | —（不使用） | Graphical abstract | |

**关键点**：中图分类号与 JEL 分类号是同一个 `classification_code` 类型，只是 `scheme` 不同。作者简介与 Author notes 是同一个 `author_note`，只是 `placement` 不同。这样英文期刊不需要新增任何 block 类型。

## 4. citation

```json
{
  "system": "numbered" | "author-year",
  "style_id": "GB-T-7714-2015" | "APA-7" | "HARVARD" | "...",
  "in_text": {
    "bracket": "[]" | "()",
    "multiple_separator": "，" ,
    "include_page": false
  },
  "reference_list": {
    "sort": "by_order" | "alphabetical",
    "templates": { "cn_journal": "{authors}：《{title}》…", "en_book": "…" },
    "authors_before_et_al": 3,
    "language_field_required": true
  }
}
```

`citation.system` 是**引用体例判别字段**，与语言无关（§11.1），枚举两个值：

| 值 | 正文引注写法 | 例 |
|---|---|---|
| `numbered` | 顺序编码制：正文以 `[1]`（或上标）标注，编号与文献表一一对应 | 国际金融研究、财经研究 |
| `author-year` | 作者-年份制：正文以「（张三，2020）」标注 | 金融研究、管理世界 |

它描述的是**正文怎么标引注**，与文献表是否编号解耦——「作者年制 + 编号表」的组合（统计研究）由 `reference_list.numbered` 表达（§19.2），不改 `system`。

与 `in_text` 其他键的关系：`in_text` 的其余键描述的都是**本刊正文引注的具体写法**，是否被引用重排消费由 `system` 决定——

- `system: "author-year"`：`bracket`、`multiple_separator`、`cn_one_author` / `en_two_authors` / `en_three_plus` 等是转换产物的依据（`citation_ref.in_text_style` 只在这里取值）；
- `system: "numbered"`：`bracket: "[]"`、`position`、实引对应要求等描述的是**编号标注**本身，重排一律不取——编号实引的刊不存在「转作者-年份」这件事。

消费点三处，口径必须一致：补录页勾选闸（仅 `author-year` 刊提供转换选项，DESIGN §1.4）、`render_from_ir.apply_citation` 入口硬闸（非 `author-year` 时记审计并整体跳过）、`citation_ref.in_text_style`（作者-年份括注与分隔符只认 `author-year` 刊的声明）。`system` 缺省按「不支持转换」对待——引用重排是越线开关，宁可不做。

`style_id` 指向**独立的引用格式化器插件**，不写在渲染器里。新增一种引用体系 = 新增一个格式化器，不改渲染器。

`reference_list.templates` 是引用体系重排（§1.4）消费的条目模板，键为 `{语言}_{类型}`（`cn_journal` / `en_book`…，与 `citation_ref.KIND` 的 slot 对应），值必须带 `{authors}` 这类**占位符**——渲染器只认带占位符的模板；纯描述式的著录写法说明（如 GB/T 7714 的「[序号]主要责任者.文献题名[M]…」）不是模板，放进来也不会被拿去改写条目。

## 5. limits：只用于提醒

```json
{
  "total":    { "value": 12000, "metric": "B" },
  "abstract": { "value": 300,   "metric": "chars_cn" },
  "figures_max": 8,
  "tables_max": 6
}
```

`metric` 取值必须对应 DESIGN.md §5.1 的三口径：

| 值 | 含义 |
|---|---|
| `A` | 字符数（不计空格） |
| `B` | 中文字符数 + 英文单词数 |
| `C` | 字符数（计空格） |
| `chars_cn` | 仅中文摘要字数 |
| `words_en` | 仅英文摘要词数 |

出处不明时填 `null` 并在 `verification.status` 标为 `unverified`，报告中输出"待确认"，**不得猜一个默认值**。

## 6. verification：诚实字段

每份规则集必须带出处，否则不得上线。

```json
{ "status": "verified", "source_url": "https://...", "verified_at": "2026-10-31", "verified_by": "人工" }
```

`status` 为 `unverified` 时，报告顶部必须显示明显提示，且不得宣称"符合该刊要求"。

### 6.1 extraction：AI 建库草稿的取舍留痕

经建库工具链（`tools/extract_journal.py`）生成的规则集，`verification` 下会多一个
`extraction` 段。其中 `extraction.unverified` 是**数组**：抽取时模型给出了值、但没能
通过引文核验（未提供原文引文，无法核验）的事实清单，每项含 `key` / `label` /
`value` / `why`。这些值一律**不写入规则集正文**；发布时草稿原样落库
（`app.py` 的 `journal_publish`），该清单随文件保留，供人工逐项核对后手工落位——
留痕不因发布而抹掉。

与 `extraction` 其余三个取舍键的分工：

| 键 | 出口 |
|---|---|
| `used` | 有原文引文且核验通过，值已写入规则集正文 |
| `inherited` | 本次未抽取，逐字段沿用基线值 |
| `dropped` | 值无效，或引文在原文中找不到（判编造），整条丢弃 |
| `unverified` | 有值但无引文，被「无引文不落盘」主闸拦下，待人工核对 |

## 7. 新增一本期刊的操作清单

只需四步，全部是数据操作：

1. 复制一份同类期刊规则集
2. 逐字段对照官方投稿须知核对（**必须看原文，不得凭记忆填**）
3. 填 `verification`
4. 跑校验：`limits.metric` 合法、`style_id` 存在、`blocks` 顺序合理

若第 2 步发现某个差异无法用现有字段表达，**先改 schema 并评审，再改数据**——不允许在渲染器里临时加分支。

---

## 8. 反模式清单

| 反模式 | 后果 |
|---|---|
| 字段名为 `clc_code`、`jel_code` 并列 | 中英共用 schema 失败，被迫两套 |
| `if journal.language == 'zh'` 出现在渲染器 | 每一本新刊都要改代码 |
| 为中英文各写一套 schema | 规则集无法互相复用，维护成本翻倍 |
| 把"是否需要中英对照摘要"做成全局开关 | 该属性属于期刊，不属于产品配置 |
| `style_id` 直接内联格式化逻辑 | 引用体系无法插件化扩展 |
| 用默认值兜底未知的字数口径 | 报告给出错误判断，比不报更糟 |

## 9. personal_fields：规则集只声明字段，不存值

个人信息字段由规则集**声明**（因为不同期刊要求的字段不同），但**不得存放任何实际值**。

```json
"personal_fields": [
  {
    "id": "author_name",
    "label_zh": "作者姓名",
    "scope": "author",
    "required": true,
    "placement": "byline",
    "prefill_from_paper": true
  },
  {
    "id": "author_affiliation",
    "label_zh": "作者单位",
    "scope": "author",
    "required": true,
    "placement": "byline",
    "prefill_from_paper": true,
    "hint": "单位全称，具体到二级学院"
  },
  {
    "id": "corresponding_email",
    "label_zh": "通讯作者邮箱",
    "scope": "paper",
    "required": true,
    "placement": "footnote"
  },
  {
    "id": "author_note_birth",
    "label_zh": "出生年",
    "scope": "author",
    "required": true,
    "placement": "footnote"
  },
  {
    "id": "author_note_title",
    "label_zh": "职称",
    "scope": "author",
    "required": true,
    "placement": "footnote"
  },
  {
    "id": "funding_number",
    "label_zh": "基金项目编号",
    "scope": "paper",
    "required": false,
    "placement": "footnote"
  }
]
```

字段语义：

| 字段 | 取值 | 说明 |
|---|---|---|
| `scope` | `paper` / `author` | 全篇一个值，还是每个作者各一份 |
| `required` | 布尔 | 必需项阻断交付，非必需项不阻断 |
| `placement` | `byline` / `footnote` / `section` | 影响稿件哪个位置，用于向用户说明改动范围 |
| `prefill_from_paper` | 布尔 | 为真时先从稿件提取，已有值不询问 |
| `hint` | 字符串 | 填写提示，用于降低返工 |

`blocks` 中的块通过 `fields` 引用这些字段：

```json
{ "type": "author_note", "placement": "footnote", "fields": ["author_note_birth", "author_note_gender", "author_note_title"] }
```

这样中文期刊的"作者简介：张三（1985—），男，江苏南京人，教授，研究方向：……"与英文期刊的 "Author notes" 复用同一套机制，只是字段清单不同。

## 10. 个人信息前置收集

### 10.1 时机

个人信息在格式化开始**之前**一次性收齐，不进入占位符机制，也不参与格式转换过程。进入渲染阶段时，文档已是完整稿。

顺序固定，不可调换：

```
上传稿件 → 结构解析 → 选定目标期刊 → 个人信息表单 → 格式转换 → 审计报告
```

"选定目标期刊"必须排在"个人信息表单"之前，因为**要问哪些字段由目标期刊的 `personal_fields` 决定**。顺序颠倒会造成两种失败：问了该刊根本不需要的字段，或者漏问了必需字段。

早期设计曾考虑"先插占位符、转换后回填"，已废弃。原因是它会引入三套额外机制（占位符语法、书签定位、未解析检查），并且存在渲染完成后无法回填的风险。前置收集把这三套机制一并取消。

### 10.2 表单生成规则

1. 字段清单 = 目标期刊 `personal_fields` 全量
2. 每个字段先尝试从稿件提取（仅当 `prefill_from_paper` 为真）
3. 稿件已有值 → 预填并允许修改，**不要求用户重输**
4. 稿件无值 → 留空，展示 `hint`
5. 每个字段标注 `placement`，让用户知道它出现在稿件的哪个位置

### 10.3 阻断规则

| 类别 | 行为 |
|---|---|
| `required: true` | 未填不得开始转换 |
| `required: false` | 可跳过；跳过即彻底不出现，**不生成任何占位符** |

被跳过的可选字段，若该刊确有要求，由审计报告在 C 档（仅报告）中提示"该刊要求 XX，本文未提供"。这条提示的措辞必须与"格式不合规"区分开——它属于信息缺失，不是格式错误。

### 10.4 跨期刊重排的二次收集

跨期刊重排是本产品的核心场景，同一篇稿子会换刊。换刊时：

1. 重新比对两本期刊的 `personal_fields` 差集
2. 只询问差集字段（例如 A 刊不要求作者简介、B 刊要求，则只补作者简介）
3. 会话内已填值保留，不清空

因此表单必须支持增量重入，不能做成"一次性提交即锁定"。

### 10.5 硬约束

1. 规则集只声明字段，不存放任何实际值
2. 个人信息不进入规则集文件；导出报告时脱敏
3. 默认仅会话级保存；跨会话复用需用户显式开启
4. 不设占位符机制：交付物中不得出现任何待填标记

### 10.6 反模式

| 反模式 | 后果 |
|---|---|
| 在选定期刊之前弹表单 | 问错字段或漏问必需字段 |
| 要求用户重输稿件中已有的姓名与单位 | 体验最差的一类失败，用户会直接放弃 |
| 把个人信息实际值写进规则集文件 | 隐私泄露，且规则集无法共享 |
| 表单提交后锁定，换刊需全量重填 | 核心场景（跨期刊重排）体验崩塌 |
| 可选字段跳过时插入占位符 | 重新引入已被取消的整套占位符机制 |
| 未填必需项仍开始转换 | 输出缺项稿件，作者可能直接投出 |

## 11. 实测修订：基于两本真实期刊稿约

对照《国际金融研究》与《金融研究》的公开投稿体例后，发现原 schema 有三处表达不足，已作修订。**这一节的存在本身说明：schema 必须被真实规则检验，不能凭经验设计。**

### 11.1 发现一：中文期刊内部引用体系就分两派

| 期刊 | 引用体系 | 具体表现 |
|---|---|---|
| 金融研究 | **作者年制** | 尾注实引，中文在前按拼音、英文在后按字母排序 |
| 国际金融研究 | **编号制** | 顺序编码制，`[序号]`，GB/T 7714-2005 |

原设计中"中文期刊 → 编号制"的隐含假设是错的。`citation.system` 必须视为与语言无关的独立维度，四条组合（中文×编号、中文×作者年、英文×编号、英文×作者年）都要能表达。

附带一条易错细节：两刊的国标版本不同（2005 与 2015），`style_id` 必须带版本号，不能只写"GB/T 7714"。

### 11.2 发现二：行距存在"固定值"写法

国际金融研究要求"行距 20 磅"，这是固定值而非倍数。原 schema 的 `line_spacing: 1.5` 无法表达。

修订为：

```json
"line_spacing": { "mode": "exact", "value_pt": 20 }
"line_spacing": { "mode": "multiple", "value": 1.5 }
```

`mode` 取 `exact` 或 `multiple`，二者不可混用。

### 11.3 发现三：表注是分层结构，不是一个字段

国际金融研究把表注拆成三层，且有各自的标点规则：

| 层 | 引导词 | 位置 | 其后标点 |
|---|---|---|---|
| 资料来源 | `资料来源` | 表格下方，最上 | **不加**标点 |
| 全表说明 | `注` | 资料来源下方 | 加句号 |
| 单元格说明 | `①②③` | 注下方 | 加句号 |

原 schema 的 `note_position` + `note_prefix` 只能表达一层。修订为 `note_layers` 数组：

```json
"note_layers": [
  { "kind": "source",  "prefix": "资料来源", "trailing_punct": false, "position": "below" },
  { "kind": "general", "prefix": "注",       "trailing_punct": true,  "position": "below" },
  { "kind": "cell",    "marker": "①②③",     "trailing_punct": true,  "position": "below" }
]
```

图注结构相同，同一套 `note_layers` 复用。

### 11.4 发现四：匿名投稿是普遍要求，需要双版本输出

两本期刊都要求正文匿名（隐去作者信息），国际金融研究更进一步：**作者信息单独设页置于正文前**，且该页字段极多（姓名、性别、身份证号、单位、职务、职称、最高学历、研究方向、主要研究成果、通讯地址、邮编、电话、邮箱）。

原设计完全没有覆盖这一点。新增顶层字段：

```json
"submission": {
  "anonymous": true,
  "anonymize_blocks": ["title", "authors", "affiliations", "author_note", "funding_statement", "acknowledgement"],
  "author_page": { "separate_page": true, "position": "before_body", "fields": ["author_name", "gender", "affiliation", "title", "email"] }
}
```

**产品含义**：一次转换要产出两份文件——**投稿用匿名稿** 与 **留档署名稿**。这不是格式细节，是一个独立交付物。同时它反过来强化了"个人信息前置收集"的决定：作者信息页的字段必须先收齐，否则匿名稿根本拆不出来。

### 11.5 发现五：标题编号存在"排除项"

国际金融研究明确规定"引言不排序号"。原 `headings.levels` 无此表达能力。

新增：`headings.unnumbered_sections: ["引言"]`，或按位序 `numbering_starts_at_section: 2`。前者更直观，建议采用。

### 11.6 发现六：官方《投稿模板》docx 是最好的样式包来源

两本期刊都提供官方 Word 模板。这直接确定了样式包的获取方式：**从官方模板里抽取 `styles.xml` 与页面设置，而不是从稿约文字反推**。稿约负责"规则"，模板负责"版式"，两者缺一不可，且必须成对维护。

### 11.7 发现七：第三方站点上的要求互相矛盾

同一本《国际金融研究》，不同第三方站点分别写成"行距 1.5 倍"与"行距 20 磅"，参考文献分别写成"GB/T 7714-2015"与"2005"。

**处理规则：只认期刊官方站点与官方模板，第三方站点一律不作为依据。** 每一份规则集的 `verification.source_url` 必须指向官方来源，且 `verified_at` 必须填写。

这条矛盾本身也是产品存在的理由之一——作者面对的就是这些互相打架的信息。

### 11.8 对示例文件的修订

`rules/examples/` 下两份示例已按本节调整：`line_spacing` 改为对象、`tables` 增加 `note_layers`、`headings` 增加 `unnumbered_sections`、新增 `submission` 段。

### 11.9 待验证的未知项

以下字段是否能表达真实需求，尚未被任何一本期刊验证，下一本填规则集时重点观察：

- 图的分辨率与格式要求（当前只有 `resolution_dpi_min`）
- 公式的编辑器要求（金融研究明确"必须用 Word 自带编辑器或 MathType，不可粘贴图片"——这条属于**校验项**，不是排版项）
- 脚注与尾注的选择（金融研究用尾注实引放参考文献，与脚注的编号关系需单独建模）
- 中英文对照标题的字号差异（国际金融研究：标题黑体二号、副标题黑体三号）

## 12. 第一份真实规则集：国际金融研究

文件：`rules/journal/gjjryj.json`。依据官网投稿指南全文 + 官方投稿模板（2023-12-18 版）解析，`verification.status = verified`。

### 12.1 稿约与模板必须成对使用

| 来源 | 提供什么 | 缺失什么 |
|---|---|---|
| 官方稿约（网页） | 规则：编号体系、引用规则、表注层次、标点规则 | 页边距、具体字号值、行距实现方式 |
| 官方模板（docx） | 版式：页面设置、字号、行距规则、实际缩进 | 规则的适用范围与例外 |

**缺任一份都填不出可用规则集。** 稿约说"行距 20 磅"，模板才能确认它是 `exact` 而非倍数；稿约说"表注置于表格下方"，模板才能确认表注是 9pt、单倍行距、首行缩进 2 字符。

### 12.2 模板解析揭示的、稿约没写的事实

1. **英文标题与 Abstract 排在参考文献之后**，不是常规的"中文摘要之后"。block 顺序必须按模板实际顺序，不能按常识推断。
2. **中文摘要的标签是"内容摘要："**，不是"摘要："。标签文字属于期刊规则，必须进规则集。
3. **关键词之间用两个半角空格分隔**，不是分号，也不是全角逗号；而英文关键词用全角逗号"，
"。同一本期刊的中英文分隔符不同。
4. **表注与图注的字体字号不同**：表注为宋体小五（9pt）左对齐，图注的"资料来源"为黑体小五（9pt）居中。原以为两者共用一套，实际不能。
5. **图注只有两层**（资料来源 + 注），**表注有三层**（资料来源 + 注 + ①②③）。同一刊内部两种结构并存。
6. **一级标题段前段后各 0.5 行**，二级三级标题"字体字号随正文"（即不放大、不加粗）。
7. **"引言"标题写作"引  言"**（两字之间两个半角空格），且不参与编号——这验证了 `unnumbered_sections` 字段的必要性。

### 12.3 字数限制的软硬之分

官方表述为"正文 17000 字左右"，**"左右"即软约束**。已记为 `strict: false`。

这是规则集必须具备的区分：硬约束（摘要 350 字以内）与软约束（正文 17000 字左右）在提醒措辞与阻断行为上完全不同。把软约束当硬约束处理，会产生大量误报，用户很快就不看报告了。

### 12.4 敏感字段

`personal_fields` 中新增 `sensitive: true`，用于身份证号、手机号、邮箱。带此标记的字段**禁止写入审计报告与任何日志**，仅在内存中传递到输出文档。

这不是可选项：身份证号一旦落进日志或被导出到报告里，是合规事故，而它出现在作者信息页的要求里，是这类期刊的常规做法。

### 12.5 解析工具

`tools/inspect_docx.py` 用于从任意 docx 反推版式参数（页面设置、样式定义、段落级字体字号行距）。新增中文期刊时先跑这个工具，能把填规则集的时间从两小时压到半小时以内。

## 13. 第二份规则集：金融研究（跨刊压力测试）

文件：`rules/journal/jryj.json`。依据官网投稿指南（2019 版）全文，**该刊不提供 Word 模板**。

两本同子领域期刊在 8 个维度上几乎相反，但共用同一套 schema：

| 维度 | 国际金融研究 | 金融研究 |
|---|---|---|
| 正文字号 | 宋体五号 10.5pt | 宋体小四 12pt |
| 引用体系 | 顺序编码制 GB/T 7714-2015 | 作者年制（自定体例 JRYJ-2019） |
| 参考文献版式 | `[1]` 序号 + 首行缩进 | 无序号 + 悬挂缩进 2 字符 |
| 分类号 | 中图分类号 + 文献标识码（固定 A） | JEL 三个 |
| 表注顺序 | 资料来源 → 注 → ①②③ | **注 → 资料来源** |
| 脚注编号 | 全文连续 | **每页单独编号** |
| 标题层级 | 最多 3 级 | 4 级 |
| 匿名方式 | 作者信息页单独成页 | 无作者页，信息录入投稿系统 |
| 官方模板 | 提供 docx | **不提供** |

### 13.1 结论一：schema 表达能力够用

两刊的差异全部由数据表达，**没有新增任何 block 类型**。中图分类号与 JEL 都是 `classification_code`，作者页有无由 `submission.author_page.separate_page` 决定。

### 13.2 结论二：暴露了四处表达不足（已补）

1. `numbering.footnotes_scope` — 需要区分 `per_page` 与 `document`，两刊相反。
2. `citation.reference_list.hanging_indent_chars` — 悬挂缩进是版式参数，不能只写在文字说明里。
3. `citation.in_text` 需容纳作者年制的多种表述（括注式、叙述式、`et al.` 触发条件），原有字段是照着编号制设计的。
4. **新增顶层字段 `assumptions`** — 官方未规定项的推定值必须显式登记（见 13.3）。

### 13.3 结论三：官方模板缺失是常态，不是例外

金融研究只给体例文字、不给模板，导致纸张、页边距、标题字号、表内字号全部无据可依。

处理方式不是悄悄填默认值，而是把它们写进 `assumptions` 数组，并在样板与规格页上明确标注「推定（官方未规定）」。理由：**推定值和期刊要求混在一起显示，用户会以为那是官方规定，一旦被编辑部退回，责任在产品。**

这也修正了 §12.1 的说法：稿约与模板成对最好，但现实中只能满足一半，产品必须有降级路径——只有稿约时，推定值必须外显。

### 13.4 结论四：渲染器做了通用化，但没有期刊特判

为支持第二本期刊，渲染器改动了六处：可选副标题、按 `scheme` 生成分类号、按 `note_layers` 数组顺序排版、作者页条件渲染、作者年制参考文献样例、悬挂缩进。

这些是**通用能力扩展**，不是期刊特判——代码里没有任何 `if journal.id == ...`。这验证了 §9.1 第 2 条达标。

### 13.5 复用率

第二本规则集的填写耗时约为第一本的三分之一，且复用了全部字段定义。主要工作量在核对官方体例原文，而非理解 schema。

## 14. 双来源核验法（官方指南 + 已发表论文）

已核对的五本期刊里，**两本的官方指南与实际排版存在系统性偏差**，且方向一致：指南写的字号比实物小一档。仅凭指南填规则集，会稳定地填错。

### 14.1 两个来源各管什么

| 来源 | 管什么 | 不可替代性 |
|---|---|---|
| 官方投稿指南 | 引用体制、字数限制、结构要件、匿名要求、图表术语 | 实物里看不出来（书评不会写「摘要限 500 字」） |
| 已发表论文 | 字体、字号、行距、版心、标题层级、题注写法 | 指南里没写或已过时 |

**单靠任何一个都会漏。** 指南给规则，实物给版式。

### 14.2 实测三个陷阱

1. **PDF 可能整体缩放**：用官方已知字号做锚点反推系数（`--anchor-pt`），不做这步会把五号读成小五。
2. **文体要对得上**：书评正文 8.9pt、研究论文 9.5pt，同一本刊不同栏目版式不同。样本文体错了，结果没有意义。
3. **字体编码可能损坏**：`unknown cid font type` 的 PDF 文字乱码，测出来的数字全是垃圾，必须直接判定不可用。

### 14.3 自动对照

```
python tools/analyze_pdf_layout.py 论文*.pdf --compare rules/journal/{id}.json
```

工具会输出逐项对照表（规则集值 / 实测值 / 偏差 / 结论），并在末尾汇总不符项。已用三本期刊做过回归验证，人为篡改行距与一级标题字号均能被抓出。

判定阈值：字号 ±0.6~0.8pt、行距 ±1.0pt、版心宽 ±3mm。纸张不一致不算缺陷——规则集按 A4 渲染以便投稿，原刊成品开本可能不同，标为「参考」。

### 14.4 已发现的偏差实例

| 期刊 | 项 | 指南 | 实测 |
|---|---|---|---|
| 中国工业经济 | 正文 | 五号 10.5pt | 11.8pt |
| 中国工业经济 | 版面 | 39 行×42 字 | 37 行×36 字 |
| 中国工业经济 | 一级标题 | 四号仿宋 14pt | 15.7pt |
| 管理世界 | 正文 | 未规定 | 9.5pt 书宋 |
| 金融研究 | 一级标题 | 未规定 | 15.9pt（原推定 12pt） |

中国工业经济这组的判定依据值得记：实测行宽 155.9mm 恰好等于 42 个五号字的宽度，说明版心未变、只是字号被放大，因此每行字数从 42 降到 36。**这类交叉验证比单点读数可靠得多。**

### 14.5 处理原则

发现偏差时，规则集以**实测值**为准（因为渲染目标是成品样式），但官方要求不能删——写进 `verification.cross_check.discrepancies`，并在 `assumptions` 里说明。理由：投稿规范与出版版式是两件事，不能因为实物没有就认为投稿不需要。

### 14.6 权威来源优先级

上面这条原则有个重要例外：**当期刊提供官方投稿模板时，模板的权威性高于实物。**

模板就是给作者照着排的；实物是编辑部排版后的结果。两者不一致时，作者该遵守的是模板。

规则集用 `verification.typography_authority` 声明取值来源：

| 取值 | 含义 | 对照时不一致的处理 |
|---|---|---|
| `template` | 有官方 Word 模板，规则集取自模板 | 标「参考」，不判为不符 |
| `guide` | 有官方明文版式规定 | 同上 |
| `published` | 无模板无明文规定，取自实物实测 | 判为「**不符**」，需修正 |

《国际金融研究》正是 `template` 的实例：正文字号、一级标题、表注、版心宽四项与实物完全吻合，唯一差异是行距——模板写「20 磅」，实物实测 15.8pt（= 10.5 × 1.5，即 1.5 倍行距）。这是编辑部在排版环节的处理，规则集保留模板的 20 磅不变。

反过来，中国工业经济与管理世界属于 `published`：官方指南要么滞后于实物（中国工业经济字号整体小一档），要么根本没规定版式（管理世界），只能以实物为准。

## 15. 第三条规律：体例写的是"版面数口径"，不是出版字号

补完《数量经济技术经济研究》与《财贸经济》后，七本里出现了三组同向偏差，可以归纳成一条可复用的判断：

**官方体例给的「五号字 + 满版字数」，通常用于折算版面数（编辑部据此算你占几页），而实际印刷用字比它大一档。**

| 期刊 | 体例写的 | 实物实测 | 推断 |
|---|---|---|---|
| 数量经济技术经济研究 | 五号、固定值 18 磅 | 11.8pt 书宋，行距 18.3 | 行距吻合，字号放大 |
| 财贸经济 | 五号、41 字×39 行 | 11.8pt 书宋，36 字/行，行距 17.2 | 版心改变，字号放大 |
| 中国工业经济 | 五号、39 行×42 字 | 11.8pt 书宋，37 行×36 字 | 版心未变，字号放大 |

三本的实物正文都落在 **11.8pt（≈小四）**，且都来自中国社会科学院系统的同一套排版流程（成品页幅统一为 216×291mm）。这不是测量误差，是出版环节的统一处理。

**结论：`typography_authority` 判为 `guide` 时，规则集保留体例值（投稿照它排），实测差异记入 `cross_check.observed_difference` 并标「参考」，不判为不符。** 因为作者投稿时该遵守的是体例，不是成品。

### 15.1 但有一种情况必须反过来

如果体例年代久远、且偏差涉及**结构**而非仅字号（如构件是否必需、层序先后、编号体系），则 `published` 优先。中国工业经济属此类：2016 年的指南连字号带构件（中图分类号那三项实物根本没有）都与现状不符。

判据很简单：**偏差只在字号/行距 → 听体例；偏差动到「有没有这一项」→ 听实物并记矛盾。**

### 15.2 本轮为承载新期刊补进 schema 的能力

新增字段全部是数据驱动，代码里没有期刊特判：

| 字段 | 用途 | 出现在 |
|---|---|---|
| `headings.level1.line_multiple` | 一级标题倍数行距（如两倍行距） | 数量经济技术经济研究、财贸经济 |
| `typography.authors` | 作者署名单独定字体字号（四号楷体 / 13.7pt 楷体） | 同上 |
| `typography.abstract` | 摘要与关键词单独定字体（仿宋 / 楷体） | 同上 |
| `typography.references` | 参考文献单独定字号（六号 7.5pt） | 财贸经济 |
| `limits.total` 可缺省 | 期刊不设总字数上限时，规格页显示「未规定」 | 数量经济技术经济研究 |
| `blocks[].separator` = 全角空格 | 关键词之间空两格、不加标点 | 数量经济技术经济研究、财贸经济 |
| `blocks[].label` 为空串 | 英文提要不加标签（财贸经济要求直接起段） | 财贸经济 |

### 15.3 顺带修掉一个会静默丢图的缺陷

渲染器原先给所有正文段落设固定行距（18/20 磅）。图片所在的段落一旦被设为固定行距，**内嵌图片会被裁到一行高，实际等于消失**——docx 里 `w:drawing` 与 media 文件都还在，只是渲染不出来，所以查文件能"验证通过"，看图才发现是空白。

修法是给 `figure` 类型单独分支：清除段落格式、居中、行距改为单倍。修复后同一份《目标落空之后》从 22 页变 26 页，7 张图全部正常显示。

**教训：凡是"清格式再套版"的实现，都要单独检查承载图片/公式/脚注的段落**，这类对象依赖段落属性，被套版改坏时不会报错。

## 16. 第九本：《世界经济》《会计研究》——权威类型的两端

补到九本后，权威来源光谱被填满：`template`（官方 Word 模板）、`guide`（官方明文版式）、`published`（只有实物）三类各有实例，且出现了"两类各管一半"的组合。

| 期刊 | 权威类型 | 拿到什么 | 缺什么 |
|---|---|---|---|
| 世界经济 | `published` | 官网投稿须知 + 官方《稿件体例调整规范》（2022-08-08）+ 3 篇实物 PDF | 无 Word 模板；投稿须知完全不含版式 |
| 会计研究 | `template` | 官网投稿须知（修订版）+ 官方《投稿格式样板》（2026-10-15，10 页） | 全文需系统下载，拿不到实物 PDF 做交叉核对 |

`会计研究` 属最省事的一类：须知写"文题小三号黑体、小标题五号黑体、其余五号宋体、1.2 倍行距"，样板里逐项对得上，两来源互证即可填完，无需实测。它的 `cross_check.status` 记为 `partial`（无实物），规格页会显示"部分核验"——缺实物不等于没依据，但也不能写成 `verified`。

### 16.1 成品 PDF 可能整体缩印，读数要标注而不是"修正"

《世界经济》官方 PDF 页幅 181×256mm，而其成品开本是 16 开（185×260mm），换算系数约 0.978；正文读数 11.3pt、行距 18.1pt，折算原值约 11.5pt / 18.5pt。

处理方式：**规则集记录读数原值，折算值写进 note 与 cross_check**。理由是作者的核对手上只有那份 PDF，写"11.5pt"会让他在 PDF 里量不出对应值；写"11.3pt"则一眼能对上。这与 §14.2「用 `--anchor-pt` 反推缩放」不矛盾——反推是为了判断"这是五号还是小五"，不是为了把数字改成好看的值。

### 16.2 倍数行距：新增 `mode: multiple` + `equivalent_exact_pt`

《会计研究》规定"正文 1.2 倍行距"。原 schema 只有 `exact`（固定值），倍数无法诚实表达；而渲染器只会写固定值。

修订为两者并存：

```json
"line_spacing": { "mode": "multiple", "value": 1.2, "equivalent_exact_pt": 18.7 }
```

- `value` 是期刊原话（1.2 倍），进规格页与审计报告；
- `equivalent_exact_pt` 是把官方样板转 PDF 后逐行实测得到的实际行距（10.5pt 宋体、1.2 倍 → 18.7pt），渲染时用它写固定值。

折算系数由**实测**给出，不写死在代码里——换字体、换字号时只需重测并改数据，渲染器不动。

### 16.3 一级标题的序号分隔符不止「、」

《世界经济》的一级标题写作「一　引言」：序号后是一个**全角空格**，不用顿号。原 `render_sample` 只认「、」，否则退回半角空格，渲染出来与实物差一个字符宽。

修法是让分隔符取 `headings.levels[0]` 的**末字符**（`render_from_ir` 早已如此），样板与转换器从此同源。规则集侧无需新增字段：`"levels": ["一　", "（一）", "1. "]` 本身就是数据。

同理，三级标题「1. 货币政策传导机制」序号后带一个半角空格，也由 `levels[2] = "1. "` 表达，代码不再自己拼空格。

### 16.4 文献表标题连冒号一起进 `blocks[].label`

《世界经济》写「参考文献：」（带全角冒号），《会计研究》写「参考文献」（不带），《数量经济技术经济研究》写「参 考 文 献」。三种写法都靠 `blocks[references].label` 承载，`typography.references_heading` 只管字体字号对齐。**label 是"文字"，typography 是"版式"，两者不能混在一个字段里。**

### 16.5 匿名要求进入体检 C 档

《会计研究》原文："稿件中不得出现可能泄露作者身份的有关信息……否则将直接退稿"；《世界经济》《金融研究》同样要求正文匿名。而工具此前只把 `submission.anonymous` 显示在规格页，体检时一句不提——作者带着署名稿投出去，被退的是他。

已加入 `compliance_report` 的 C 档（仅报告）：该刊 `anonymous: true` 而稿件前置区仍有作者行时，点名并给出原文片段，措辞明确"这属于身份信息，不是格式错误，本工具不会代删"。不自动删除，是因为删作者名属于 D 档；双版本输出（匿名稿 + 署名稿）仍是未实现项。

### 16.6 样板渲染器必须消费全部版式字段

补《世界经济》时发现：`render_sample` 的参考文献条目一直用正文字号，而 `typography.references` 只有转换器在读——于是《财贸经济》的样板里文献是 10.5pt，规则集写的是 7.5pt。**样板与规则集漂移，比没有样板更糟**（§11.1）。

同一轮还补了两处：英文作者块、英文分类号块（JEL）此前样板直接跳过，导致《世界经济》样板缺 JEL 行。修完后九本重出，文献字号、英文三件套与规则集一致。

**判据：规则集里任何一个 `typography.*` 键，样板都必须能看出来。** 看不出来就是渲染器漏读，不是"该刊没这项"。

## 17. 第十本：《经济管理》——只有文字体例也能填满版式

《经济管理》不提供模板，也没有开放的正文 PDF，但官网《投稿指南（2022 年修订）》后面附了一份《经济管理》体例规范，把每一项的字体字号逐个写死：

| 构件 | 官方规定 |
|---|---|
| 论文标题 | 四号宋体，≤20 字，可加副标题 |
| 内容提要 / 关键词 | 中文五号楷体（不得写「摘要」「内容摘要」）；关键词 3–5 个，空格隔开 |
| 中图分类号 | 五号楷体，作者填写 |
| 正文 | 中文五号宋体，英文五号 Times New Roman |
| 一级标题 | 「一、」四号宋体居中；英文四号 Times 加粗 |
| 二级 / 三级 / 四级 | 「1.」单独成行不接排；「（1）」「1）」后接排 |
| 脚注 | 小五宋体，①②③，每页重编号 |
| 图表 | 图内文字小五宋体，且**图表内全部用中文**；图下必须写「资料来源：作者整理」 |
| 参考文献 | 顺序编码制，正文写（作者，年份）<sup>[6]</sup>；中文须注明期刊/出版社所在城市 |

**结论：`typography_authority = guide` 不等于"版式不全"。** 只要官方把字号写到构件级，就不必去量实物；反过来，只有"正文五号宋体"一句的指南（如《南开管理评论》2025 版）也不足以填规则集，仍需实物。判断标准是**每条构件是否都有字号**，不是"有没有模板"。

### 17.1 两个新的 schema 表达

1. **区间型字数限制**：英文长摘要要求「3600～4100 字符（不计空格），占一个页码」，既不是单一上限也不是词数。`limits.abstract_en` 用 `min`/`max` + `metric: "A"` 表达，规格页渲染为「3600～4100 字符」。原 `render_spec` 只认 `value`，遇到区间会 KeyError，已改为三分支（单一上限 / 区间 / 仅上限）。
2. **作者信息页的字段来自 `personal_fields`**：该刊要求正文前单独一页放 8 要素，样板页的标签直接取 `personal_fields[].label_zh`。缺字段时页面会退化成显示英文 id（`abstract:`、`keywords:`），所以作者页要用的 id 必须在 `personal_fields` 里登记齐全——这条已写进本节，避免下次再踩。

### 17.2 正文引用写「和」「等」，禁用 & / and / et al.

该刊明确规定外文引注写作「Yuanli 和 Karen（1986）」「Yuanli 等（1986）」，不得写 `&`、`and`、`et al.`——与《世界经济》的 "Stock and Watson" 写法正好相反。这再次说明引用体系必须逐刊配置（`citation.in_text`），不能按"英文就用 and"的常识推断。

### 17.3 当前十本清单与权威类型分布

| 权威类型 | 期刊 |
|---|---|
| `template`（官方 Word 模板） | 国际金融研究、会计研究 |
| `guide`（官方明文版式） | 中国工业经济、数量经济技术经济研究、财贸经济、经济管理 |
| `published`（仅实物实测） | 金融研究、财经研究、管理世界、世界经济 |

十本覆盖四种标题体系（`一、`/`一　`/`一`）、两种引用体系（编号制 5 本、作者年制 5 本）、三种表注层序（注→来源、来源→注、仅注）。第八、九、十本连续三本都是"纯数据操作"，未因新增期刊修改渲染器——§9.4 的扩展性验收达标。

## 18. 英文期刊：schema 够用，缺的是三件套与几个 en-only 块

第十二本《China Economic Review》作为英文刊 PoC 跑通后，可以给出明确结论：**扩展英文期刊不是重写，而是补齐三件被 §9.2 点名插件化的部件，加上语言能力归属的重新对表。**

### 18.1 已经不需要改的部分

| 能力 | 现状 |
|---|---|
| 块类型 | `title` / `authors` / `affiliations` / `abstract` / `keywords` / `classification_code(JEL)` / `body` / `references` / `appendix` 全部复用，未新增类型 |
| 语言能力 | 由 `journal.language` 决定；英文刊不再追加中英对照摘要（§9.3 的判断成立） |
| 图注表注 | `note_layers` 直接表达 "Note: " 一层 |
| 页面 | `page.size_mm` / `margin_mm` 通用 |
| 双匿名 | `submission.anonymous` + `author_page.separate_page` 已经能表达 Elsevier 的"题名页与匿名稿两个文件" |

### 18.2 本轮为英文刊补的三处能力

1. **标题编号体系（`headings.numbering = "numeric"`）**：`1.` / `1.1` / `1.1.1`。原渲染器把一级标题硬编码成"一、二、三"，现在按 `numbering` 分派：中文用 `levels[0]` 末字符作分隔符，数字体系每级都用空格。`render_sample` 与 `render_from_ir` 同步改。
2. **样板占位文字数据化（`sample` 段）**：英文刊的样板若沿用"张　三""表1 主要变量描述性统计"，规格页会显得不专业。现在 `sample` 可提供 title/abstract/keywords/表格/图注/作者页说明等占位文字，缺省仍用中文，已有十二本刊的产物不变。
3. **纯英文刊不重复渲染"英文四件套"**：原逻辑默认"中文主体 + 文末英文摘要"，英文刊会整篇重复。现在按"是否存在中文摘要块"判断，纯英文刊跳过该段；英文分类号（JEL）改为**按 blocks 顺序**决定前置还是末尾——《世界经济》的 JEL 在文末，CER 的 JEL 紧跟关键词。

### 18.3 仍然缺的三件（英文刊真正的门槛）

| 部件 | 现状 | 补齐方式 |
|---|---|---|
| 引用格式化器插件 | `style_id` 已能指向 `APA-7`，但**没有插件真的把条目改写成 APA**；目前只做悬挂缩进，条目文本原样保留 | 新增 `tools/cite_styles/` 目录，每个 style 一个函数：读 `reference_item` 的字段（作者/年/题/刊/卷期页/DOI），输出目标样式。属 §9.2 允许的"新增插件"，不动渲染器 |
| 样式映射表 | 英文刊的 Word 样式名（Title/Heading 1/Body Text）与中文刊不同 | 规则集内加 `style_map`，代码只查表 |
| 标题编号的自动生成 | 数字体系目前只生成"第几级 + .1"，不支持 1.1.2 的第三段递增 | 编号生成器按 `levels` 模板做多段递增 |

### 18.4 英文刊特有的块与校验（下一轮）

- `highlights`（3–5 条、每条 ≤85 字符、独立文件）、`author_vitae`（≤100 词）、生成式 AI 声明节（须在参考文献之前）——`highlights` 已进 blocks，后两项仅以 `statements` / `submission.ai_declaration` 声明，尚未参与渲染与校验。
- 版面差异：Word 稿件单栏、双栏仅限 LaTeX。当前渲染器只出单栏 Word，LaTeX 通道不做（明确不承诺）。
- 校验口径要换：英文刊看重"摘要 ≤250 词""关键词 1–7""JEL ≤6""Highlights 字符数"，`limits.metric` 需支持 `words_en` 与 `chars`（已支持 `words_en`，`chars` 待补）。

### 18.5 结论

**schema 不需要为英文刊新增任何 block 类型**，验证了 §9.1 第 3 条。真正的成本在三处插件（引用格式化器、样式映射、编号生成器）与英文专属校验，属于 §9.1 允许的"新增引用格式化器插件"范围内，不算扩展性失败。

## 19. 第二十本：《统计研究》——付费墙后的一份 PDF 值多少

这本是 `needs.md` 里"最有用的一样东西是正文 PDF"的第一次兑现。此前它只能停在"须知结构齐全、通篇无字号"的 A 类候选里；三篇 2026 年第 10 期正文 PDF 到手后，一个下午从零做到 `verified`。

### 19.1 实测读数（3 篇一致）

| 构件 | 读数 | 说明 |
|---|---|---|
| 开本 / 版心 | 210×285mm / 161×243mm | 大 16 开；投稿按 A4，页边距取实测 上22 下20 左25 右24mm |
| 正文 | 宋体 10.5pt，行距 17pt，首行缩进 2 字 | 3 篇完全一致 |
| 中文标题 | 小标宋 26pt 居中 | PDF 内嵌字体 TTCF48015CtCID＝方正小标宋 |
| 中文作者 | 楷体 14pt 居中 | 姓名间空一格 |
| 内容提要 / 关键词 | 9pt，行距 15pt | 提要为「标签黑体 + 正文宋体」，关键词**整行黑体** |
| DOI / 三码行 | 9pt 黑体 | DOI、中图分类号、文献标识码、文章编号连排，只在关键词下出现一次 |
| 英文标题 / 作者 / Abstract | 14pt Times 加粗 / 10.5pt / 9pt | 与中文摘要同置首页，不在文末 |

| 表 / 图 | 表内 7.5pt；表题表上图下，9pt 黑体居中，题号与题名空两格 | 表注 7.5pt「注：」一行 |

| 脚注 | 7.5pt，①②③ 每页重排 | 标题用 * 号注基金与通讯作者 |

### 19.2 一个此前没人表达过的组合：正文作者—年份 + 文献表编号

正文写「（De La Grandville，1989；郝枫和盛卫燕，2014）」，文献表却是 `[1]`…`[35]` 的编号列表，且编号只按"中文拼音在前、外文按字母在后"排，与正文的先后无关——**编号只是列表序号，不是引注号**。

原 schema 只有 `system: numbered` / `system: author-year` 两个互斥值，表达不了这个组合。新增两个字段：

```json
"reference_list": {
  "numbered": true,
  "number_format": "[1]",
  "number_role": "list_index_only"
}
```

- `numbered` 描述**文献表**是否编号，与 `citation.system`（正文怎么写）解耦；
- `number_role: list_index_only` 说明编号不对应正文，规格页据此显示「[1]（仅作列表序号，正文不标注）」。

修完之后发现 `render_spec` 原来按 `system` 判断是否编号，凡是"作者年制 + 编号表"的刊都会显示「不编号」。已改为按 `reference_list.numbered` 判断。

### 19.3 本轮补的四处通用能力

1. **样板按 `typography.classification` 画号段行**。此前号段统一用正文字号，`cjyj` 写了 9.5pt 黑体也画不出来（§16.6 的老问题复现）。顺带补上 `doi` 块的渲染与 `blocks[].sample_value`（允许规则集直接给样例值）。
2. **英文四件套按 blocks 顺序决定位置**。此前一律追加在参考文献之后；《统计研究》《财经研究》这类"中英文摘要同置首页"的刊会整段错位。现在按"英文块的位置是否早于 body"分派。
3. **前置区段间距**。26pt 标题原来与下一行贴死。改为标题前后 0.2/0.25 倍字号、作者后 0.9 倍、英文标题前 0.9 倍——都是排版常识，但此前代码里一段都没有。
4. **文末作者简介**。`personal_fields[].placement = "back_matter"` 时，简介不再塞进首页脚注，而是插到参考文献之后、按 `typography.author_note` 排版；匿名稿把标签与内容两段一并删掉。

另外两处小的：
- `render_sample` 的文献编号由渲染器按条数生成（`number_format` 只写样式），不再要求示例里手写 `[1][2][3]`——`jjgl`、`jqte` 的样板此前因此缺编号。
- 转换器按 `abstract` / `keywords` **分别**取字号字体（《统计研究》提要是宋体、关键词是黑体，原来一律按摘要样式画），并新增「关键词分隔符归一」（稿件用空格，该刊要求分号）。

### 19.4 判据更新

`needs.md` 里那句「最有用的一样东西是正文 PDF」不是客套：**一份出版社原始版式的 PDF，能替代十条官网链接**。但要注意验收——CNKI 移动端重排版（全篇同字号）量不出任何东西，必须是出版社排版版式。判断方法是选中一段正文，看字号是否有层次。

| `template`（官方 Word 模板） | 国际金融研究、会计研究 |
| `guide`（官方明文体例） | 中国工业经济、数量经济技术经济研究、财贸经济、经济管理、南开管理评论、外国经济与管理、上海财经大学学报、CER/JDE/ECMO/JAE/JCE/CWE（英文刊官方指南不涉版式，版式均推定） |

### 20.2 新增 block 类型：`column_name`

前二十本里，schema 一次都没加过 block 类型（§18.5 甚至下过「schema 不需要为英文刊新增任何 block」的结论）。这次破了这个纪录，因为「·构建新发展格局·」既不是副标题、也不是分类号：

```json
{ "type": "column_name", "required": false, "sample_value": "·构建新发展格局·" }
```

`required: false` 是关键——3 篇样本里 1 篇没有栏目名，说明它由编辑部按栏目加，不是作者必填项。写成必填会让体检报告对每篇无栏目名的稿子报"缺 1 项"，那是误报。

**判据：新增 block 类型只在"这个构件没有任何既有类型能表达"时才允许。** 栏目名满足这一点：它是期刊层面的分类标识，不参与作者信息，也不属于标题族。

### 20.3 新增能力：字间距（`letter_spacing_pt`）

《统计研究》的一级标题每字加宽约 0.8pt，当时判断"影响不大，记录不实现"（§19.1）。《经济研究》的标题加宽到 1.3pt、而且是**主标题**，不实现就不像了。

实现方式是 Word 的字符间距（`w:rPr/w:spacing/@w:val`，单位 twips，1pt = 20twips）：

```json
"title": { "size_pt": 21.6, "letter_spacing_pt": 1.3 }
```

两个渲染器都读这个键；未声明的刊不写该元素，产物不变。至此 §19.1 记下的那条"未实现"可以划掉了——只需在统计研究的规则集里补 `"letter_spacing_pt": 0.8`。

### 20.4 一级标题分隔符：从取末字符改成取序号之后

`sep = levels[0][-1]` 这个写法在《世界经济》（`一　`）和《统计研究》（`一、`）上都对，到《经济研究》就崩了：它的 `levels[0]` 是 `"一、 "`（顿号＋空格），末字符是空格，于是渲染成「一 引言」——**顿号被吃掉**。

改为 `sep = levels[0][1:]`，即"去掉首个序号字符后的全部内容"：

| 期刊 | `levels[0]` | `[-1]` 得到 | `[1:]` 得到 |
|---|---|---|---|
| 世界经济 | `一　` | 全角空格 ✓ | 全角空格 ✓ |
| 统计研究 | `一、` | 顿号 ✓ | 顿号 ✓ |
| 经济研究 | `一、 ` | 空格 ✗ | 顿号＋空格 ✓ |

三本实测：「一　引言」/「一、引言」/「一、 引言」全部正确。**取末字符只在分隔符恰好是一个字符时成立**，这个假设此前没被打破，纯属运气。

### 20.5 英文区注入位置：由规则集决定，不靠锚点常量

《经济研究》的英文部分在文末，《统计研究》在首页。而 `apply_details` 插入英文块用的是固定的锚点链（关键词 → 英文标题 → 作者 → 单位 → 摘要），于是经济研究的英文摘要被插在首页、紧随中文关键词——**布局直接不合刊**。

改为：读规则集 `blocks` 里英文块的位置，若排在 `body` 之后，就把英文标题的锚点换成参考文献之后，其余英文块仍走原来的链式锚点。

这里有个坑：第一版把**所有**英文块的锚点都换成文末，结果链断了（每个块都独立插在同一位置），Summary 跑到单位前面去了。**只有链头需要换锚点**，后序靠 `type_last_el` 接续。

### 20.6 参考文献行距此前一直被正文行距覆盖

`reference_item` 分支写的是 `line_pt=line_pt`（正文行距），规则集里的 `typography.references.line_spacing` 从来没被读过。于是《经济研究》的文献条目按 17.2pt 排，而实物是 14.2pt——22 页的稿子被撑成 23 页。

修完后 14.2pt 生效，页数回到 22。**这条与 §16.6 是同一类错误**：规则集里写了、渲染器不读，产物与规则集漂移。下次新增 `typography.*` 键时，先确认两个渲染器都消费它。

### 20.7 非整磅字号的处理（延续 §16.1）

《经济研究》的读数全是非整磅：11.8 / 14.7 / 21.6 / 12.7 / 15.4 / 9.8 / 8.8，按 0.983 折算约为 12 / 15 / 22 / 13 / 15.6 / 10 / 9 pt。

处理方式与《世界经济》一致：**规则集记录读数原值**，折算关系写进 `cross_check.observed_difference`。理由是作者的核对手上只有那份 PDF，写 11.8 他能量出来，写 12 他量不出。

### 20.8 二十一本来历

| 权威类型 | 数量 | 期刊 |
|---|---|---|
| `template` | 2 | 国际金融研究、会计研究 |
| `guide` | 8 | 中国工业经济、数量经济技术经济研究、财贸经济、经济管理、南开管理评论、外国经济与管理、上海财经大学学报 + 6 本英文刊（官方指南不涉版式，版式推定） |
| `published` | 6 | 金融研究、财经研究、管理世界、世界经济、统计研究、**经济研究** |

至此，中文经管顶刊里"靠实物才能做"的四本（管理世界、世界经济、统计研究、经济研究）已全部拿下。**四本都是用户给 PDF 才做成的**——这不是巧合，是付费墙的结构性结果。

## 21. 第二十二本：《中国管理科学》——双栏刊怎么记，数字编号怎么写

三篇网络首发 PDF 到手后，这本刊带来两个前二十一本没遇到的问题：**印刷版是双栏**，以及**数字编号有两种写法**（`1` 与 `1.`）。

### 21.1 实测读数

| 构件 | 读数 | 备注 |
|---|---|---|
| 开本 / 分栏 | A4，**双栏**；版心 172mm、栏间距 9.1mm、每栏约 81mm | 左空 20mm、右空 18mm |
| 正文 | 宋体 10.5pt，行距 **13.6pt**，缩进 2 字 | 双栏行距比单栏紧得多 |
| 标题 / 作者 / 单位 | 22pt 宋体居中 / 14pt 楷体 / 10.5pt 仿宋 | 作者间用逗号，单位写「（单位，省市 邮编）」 |
| 摘要 / 关键词 | 10.5pt；标签「摘  要：」字间空一格；关键词用分号 | 与正文同号同性 |
| 三码 | 中图分类号 + **文献标志码**（该刊写「志」不是「识」） | 同一行 |
| 一级 / 二三级标题 | **「1 引言」14pt 左对齐**（无点号）/「2.3」「2.3.1」10.5pt 顶格 | 二三级均不缩进 |
| 表 / 图 | 表内 9pt，表题 9pt 在表上；图题 9pt 在图下 | 跨页写「续表2」；本刊表下不加注 |
| 参考文献 | 标题 14pt 顶格；条目 9pt、[1] 编号、**中英双语对照**、悬挂缩进 2 字 | 中文条目下附英文译名 |
| 英文区 | 标题 10.5 加粗 / 作者单位 9 / Abstract 10.5（行距 12.1） | 置文末且**通栏**，不随正文分栏 |

### 21.2 双栏：记录它，但不渲染它

前二十一本的 `page.columns` 全写 1，即便其中几本印刷版也是双栏——当时没有字段记录"实物是几栏"，这个信息一直丢着。

新增 `page.printed_columns`：

```json
"columns": 1,
"printed_columns": 2,
"printed_columns_note": "实物为双栏：版心 172mm、栏间距 9.1mm；投稿稿按单栏渲染，双栏由编辑部排版"
```

两个字段分工明确：`columns` 是**投稿稿**的分栏（工具实际渲染的），`printed_columns` 是**实物**的分栏（供人核对）。投稿阶段单栏是通例，编辑部拿到稿子自己排双栏——工具若强行排双栏，作者反而不好改内容。

配套的 assumptions 里写清"单栏渲染时标题断行可能与双栏实物不同"：22pt 标题在 81mm 栏宽里断成三行、在 166mm 单栏里断成两行，这是版心宽度差异的必然结果，不是错误。

### 21.3 数字编号的两种写法：`1` 与 `1.`

《中国管理科学》写「1 引言」，CER 写「1. Introduction」。原代码 `head_no` 硬编码 `f"{n}."`，只能出后者。

改成**以 `levels[0]` 为模板替换数字**：

| 期刊 | `levels[0]` | 结果 |
|---|---|---|
| 中国管理科学 | `1` | `1 引言` |
| CER | `1.` | `1. Introduction` |

二级三级同理（`1.1` / `1.1.1` 的数字按层级依次替换）。两个渲染器同步改，没有特判。

同一轮还修了 `render_from_ir` 的一个老问题：二级三级编号原来也是硬编码 `f"{a}.{b}"`，遇到模板不同的刊同样会错，现在一并走模板。

### 21.4 双语参考文献：`\n` 让一段内换行

该刊每条中文文献下面要跟一条英文译名，两者算**同一条**（不各占一个编号）。规则集里用 `\n` 连接：

```json
"examples": [
  "[1] 庄存波, 刘检华, 张雷. 工业5.0 的内涵……[J]. 机械工程学报, 2022, 58(18): 75-87.\nZhuang C B, Liu J H, Zhang L. Connotation……[J]. Journal of Mechanical Engineering, 2022, 58(18): 75-87."
]
```

`add_para` 原来把 `\n` 当普通字符，现在按段内换行处理（`run.add_break()`）。规则集新增 `reference_list.bilingual`，但**工具不生成英文译名**——译名须作者自备，工具只校验编号、缩进与排序。这一点写在 `bilingual_note` 里，免得被误认为"能自动翻译"。

### 21.5 空注层：`note_layers: []` 是合法值

该刊表下不加注。规则集写 `"note_layers": []`，结果三个工具全部 KeyError / IndexError（`render_spec` 取 `[0]`、`render_from_ir` 取 `[0].get()`、`render_sample` 直接下标）。三处都已改成"空列表就说不加注"。

**这是个通用问题**：schema 允许空数组，代码却默认非空。凡是"可能有 0 个"的数组字段，取首元素前都该判空。

## 22. 第二十三本：《管理科学学报》——官方写着「1 引言」，实物是「0 引言」

这本是少见的"文档与实物直接打架"的案例：官网《投稿指南》白纸黑字写「1 引言（正文一级标题）」，而 2026 年第 9 期两篇印刷版都从「0 引言」起编。规则集按实物走。

### 22.1 官方明文（8 条，全部进规则集）

| 项 | 官方原文要点 |
|---|---|
| 结构 | 中文主题→作者→工作单位→摘要→关键词→1 引言→分节→结论→参考文献→**英文主题→作者→单位→摘要→关键词→附录** |
| 字数 | 全文不超过 8 千字为宜，综述性可放宽到 12 千字（含图表） |
| 摘要 | 不超过 300 字 |
| 关键词 | 3—8 个（上限比多数刊宽） |
| 公式 | 独立的数学公式按先后顺序统一编号 |
| 表格 | 编号、题目、各栏须填全，不得简略 |
| 引用 | 正文只写序号〔1〕〔2〕……，文献按文中出现先后排列 |
| 匿名 | 《关于新投稿上传匿名稿件的通知》：去除作者、单位、基金资助信息，**包括英文作者、单位等** |

其中「〔1〕」是**六角括号**，不是方括号——国内刊物里并不少见，但工具此前只会输出 `[1]`／`［1］`／`（1）`，本轮补了六角括号分支。

### 22.2 实测读数（2 篇印刷版 + 1 篇网络首发）

| 构件 | 读数 |
|---|---|
| 开本 / 分栏 | 210×285mm **双栏**；版心 165mm、栏距约 5mm、每栏约 80mm；左空 23.7mm、右空 21.3mm |
| 正文 | 宋体 10.3pt，行距 17.0pt，缩进 2 字 |

| 表 / 图 | 表内 7.8pt；表题 7.8pt 黑体在表上、表注 7.8pt「注:」 |

### 22.3 新字段：`headings.intro_number`

引言编号有三种写法，此前只能表达两种：

| 期刊 | 写法 | 表达 |
|---|---|---|
| 世界经济 | `一　引言` | `levels[0] = "一　"` |
| 中国管理科学 | `1 引言` | `levels[0] = "1"`，默认从 1 起 |
| **管理科学学报** | **`0 引言`** | `intro_number: 0`，后续从 1 起 |

新增 `headings.intro_number`（默认 1）。两个渲染器的一级计数器初值改为 `intro_number - 1`，第一个一级标题即得该值。实测：管理科学学报出「0 引言→1 文献综述」，其余刊仍从 1 起，无一处特判。

### 22.4 文档与实物冲突时以实物为准

官网写「1 引言」，实物写「0 引言」。这不是官网写错——指南可能滞后于 2020 年前后的版式调整。按 §14.6「有实物时实物优先」处理，并把这个差异写进 `cross_check.confirmed`，让读者知道我们是**故意**与官网不一致。

写规则集的人容易犯的错，是拿官方文档当唯一真源。文档说"应该怎样"，实物说"实际怎样"，投稿被卡的往往是后者。
